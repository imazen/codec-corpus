# imazen-26/splits — browsable split folders

`train/`, `validate/`, `test/` mirror the class-folder structure with **relative
symlinks** into `../../<class>/…`, so each bucket is browsable without duplicating
bytes. Generated by `../scripts/make_canonical_split.py` from the canonical last-digit
rule (see [`../manifests/README.md`](../manifests/README.md) — the TSVs there are the
authoritative record; this tree is a convenience view).

Notes:

- On a checkout without the image bytes (images are distributed via R2, not git), the
  links dangle harmlessly — sync the class folders first and the links resolve.
- On Windows checkouts without symlink support (`core.symlinks=false`), git
  materializes links as small text files containing the target path; use the TSVs, or
  re-run the generator on a POSIX checkout.
- Never commit real files into these folders — only the generator writes here.
